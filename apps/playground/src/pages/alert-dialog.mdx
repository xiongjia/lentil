  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
  Button,
} from "@lentil/ui";

# Alert Dialog

A modal dialog built on Radix Alert Dialog, designed for critical confirmations that interrupt the user. Unlike a regular Dialog, the overlay cannot be dismissed by clicking outside.

## Basic

```tsx preview
<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="outline">Delete Account</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
      <AlertDialogDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>Continue</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## Destructive Action

```tsx preview
<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="destructive">Delete Project</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Delete Project</AlertDialogTitle>
      <AlertDialogDescription>
        Are you sure you want to delete this project? All of its data,
        including tasks, files, and comments will be permanently removed.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction className="bg-destructive text-destructive-foreground hover:bg-destructive/90">
        Delete
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## API

| Component                 | Props               | Description              |
| ------------------------- | ------------------- | ------------------------ |
| `AlertDialog`             | `open`, `onOpenChange` | Root container         |
| `AlertDialogTrigger`      | `asChild`           | Trigger element          |
| `AlertDialogContent`      | `className`         | Modal content panel      |
| `AlertDialogHeader`       | `className`         | Header wrapper           |
| `AlertDialogTitle`        | `className`         | Dialog title             |
| `AlertDialogDescription`  | `className`         | Dialog description       |
| `AlertDialogFooter`       | `className`         | Footer wrapper           |
| `AlertDialogAction`       | `className`         | Confirm action button    |
| `AlertDialogCancel`       | `className`         | Cancel button            |
| `AlertDialogPortal`       | —                   | Portal container         |
| `AlertDialogOverlay`      | `className`         | Backdrop overlay         |
