# Dialog

A modal dialog built on Radix Dialog, used for focused interactions that require user attention or input.

## Basic

```tsx preview
<Dialog>
  <DialogTrigger asChild>
    <Button variant="outline">Open Dialog</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Dialog Title</DialogTitle>
      <DialogDescription>
        This is a simple dialog with a title and description. Click outside or
        press Escape to close.
      </DialogDescription>
    </DialogHeader>
    <div className="text-sm text-muted-foreground">
      Dialog body content goes here. You can put any React components inside.
    </div>
  </DialogContent>
</Dialog>
```

## With Footer

```tsx preview
<Dialog>
  <DialogTrigger asChild>
    <Button>Edit Profile</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit profile</DialogTitle>
      <DialogDescription>
        Make changes to your profile here. Click save when you're done.
      </DialogDescription>
    </DialogHeader>
    <div className="flex flex-col gap-4 py-2">
      <div className="text-sm">
        <label className="block font-medium mb-1">Name</label>
        <input className="flex h-9 w-full rounded-md border border-input bg-transparent px-3 py-1 text-sm shadow-sm" placeholder="Your name" />
      </div>
      <div className="text-sm">
        <label className="block font-medium mb-1">Email</label>
        <input className="flex h-9 w-full rounded-md border border-input bg-transparent px-3 py-1 text-sm shadow-sm" placeholder="your@email.com" />
      </div>
    </div>
    <DialogFooter>
      <DialogClose asChild>
        <Button variant="outline">Cancel</Button>
      </DialogClose>
      <Button type="submit">Save changes</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Destructive Confirmation

```tsx preview
<Dialog>
  <DialogTrigger asChild>
    <Button variant="destructive">Delete Item</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Delete Item</DialogTitle>
      <DialogDescription>
        Are you sure you want to delete this item? This action cannot be undone.
      </DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose asChild>
        <Button variant="outline">Cancel</Button>
      </DialogClose>
      <Button variant="destructive">Delete</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## API

| Component            | Props               | Description              |
| -------------------- | ------------------- | ------------------------ |
| `Dialog`             | `open`, `onOpenChange` | Root container         |
| `DialogTrigger`      | `asChild`           | Trigger element          |
| `DialogContent`      | `className`         | Modal content panel      |
| `DialogHeader`       | `className`         | Header wrapper           |
| `DialogTitle`        | `className`         | Dialog title             |
| `DialogDescription`  | `className`         | Dialog description       |
| `DialogFooter`       | `className`         | Footer wrapper           |
| `DialogClose`        | `asChild`           | Close button wrapper     |
| `DialogPortal`       | —                   | Portal container         |
| `DialogOverlay`      | `className`         | Backdrop overlay         |
