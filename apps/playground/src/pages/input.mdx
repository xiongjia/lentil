# Input

Text input field for collecting user data. Supports all native HTML input types,
and provides specialised variants with built-in validation for common use cases.

## Basic

```tsx preview
<div
  style={{
    display: "flex",
    flexDirection: "column",
    gap: "0.75rem",
    maxWidth: "24rem",
  }}
>
  <Input placeholder="Type something..." />
  <Input placeholder="Disabled" disabled />
  <Input defaultValue="Read-only value" readOnly />
</div>
```

## Validation States

Use `InputStatus` for manual error / success control.

```tsx preview
<div
  style={{
    display: "flex",
    flexDirection: "column",
    gap: "0.75rem",
    maxWidth: "24rem",
  }}
>
  <label className="text-sm font-medium">Error</label>
  <InputStatus
    defaultValue="invalid@"
    error="Please enter a valid email address"
  />

  <label className="text-sm font-medium">Success</label>
  <InputStatus
    defaultValue="user@example.com"
    success="Looks good"
  />
</div>
```

## API

### Input

| Prop          | Type                     | Default  | Description                 |
| ------------- | ------------------------ | -------- | --------------------------- |
| `type`        | `HTMLInputTypeAttribute` | `"text"` | Native input type           |
| `placeholder` | `string`                 | —        | Placeholder text            |
| `disabled`    | `boolean`                | `false`  | Disable the input           |
| `readOnly`    | `boolean`                | `false`  | Make input read-only        |
| `required`    | `boolean`                | `false`  | Mark as required            |
| `className`   | `string`                 | —        | Additional CSS classes      |
| `...props`    | `InputHTMLAttributes`    | —        | All native input attributes |

The `Input` component accepts all standard HTML `<input>` attributes including `min`, `max`, `maxLength`, `pattern`, `autoComplete`, `onChange`, `onBlur`, `onFocus`, etc.

### InputStatus

| Prop        | Type                     | Default | Description                             |
| ----------- | ------------------------ | ------- | --------------------------------------- |
| `error`     | `string`                 | —       | Error message (shows red AlertCircle)   |
| `success`   | `string`                 | —       | Success message (shows green CheckCircle2, hidden if error is set) |
| `type`      | `HTMLInputTypeAttribute` | `"text"`| Native input type                       |
| `className` | `string`                 | —       | Additional CSS classes                  |
| `...props`  | `InputHTMLAttributes`    | —       | All native input attributes             |

### InputEmail / InputPassword / InputURL / InputTel / InputNumber

Specialised inputs with built-in validation and internal `touched` state. Accept all
`InputStatus` props plus:

| Prop          | Type                               | Default              | Description                              |
| ------------- | ---------------------------------- | -------------------- | ---------------------------------------- |
| `validate`    | `(value: string) => string`        | —                    | Custom validator (return `""` when valid) |
| `successText` | `string`                           | `"Valid …"`          | Set to `""` to hide success feedback      |
| `minLength`   | `number`                           | `8`                  | *(InputPassword only)* Minimum length     |
| `showToggle`  | `boolean`                          | `false`              | *(InputPassword only)* Show/hide button   |
| `min` / `max` | `number`                           | —                    | *(InputNumber only)* Number range         |
