# Sheet

A slide-over panel built on Radix Dialog, used for supplementary content, mobile menus, and drawers.

## Basic

```tsx preview
<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline">Open Sheet</Button>
  </SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Sheet Title</SheetTitle>
      <SheetDescription>
        This is a simple sheet with a title and description.
      </SheetDescription>
    </SheetHeader>
    <div className="mt-4 text-sm text-muted-foreground">
      Sheet content goes here. You can put any React components inside.
    </div>
  </SheetContent>
</Sheet>
```

## API

| Component           | Props               | Description              |
| ------------------- | ------------------- | ------------------------ |
| `Sheet`             | `open`, `onOpenChange` | Root container         |
| `SheetTrigger`      | `asChild`           | Trigger element          |
| `SheetContent`      | `side`, `className` | Panel content (`top` `right` `bottom` `left`) |
| `SheetHeader`       | `className`         | Header wrapper           |
| `SheetTitle`        | `className`         | Dialog title             |
| `SheetDescription`  | `className`         | Dialog description       |
| `SheetFooter`       | `className`         | Footer wrapper           |
| `SheetClose`        | `asChild`           | Close button wrapper     |
